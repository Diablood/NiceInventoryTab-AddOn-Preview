# Roadmap

## Active sequence

### 0.1.0-dev - Establish project foundation

Create the repository structure, metadata, build, workflow, documentation and compatibility bootstrap.

### 0.1.1-dev - Add compatibility diagnostics

Verify the presence and signatures of Nice Inventory Tab's `Prefix` and `AddonCheckBoxes` methods. Disable the add-on safely when the expected API is unavailable.

### 0.1.2-dev - Add preview visibility control

Add an optional preview toggle through Nice Inventory Tab's add-on checkbox extension point.

### 0.1.3-dev - Add rotatable pawn portrait

Render the selected pawn with current apparel and support four orientations.

### 0.1.4-dev - Add layout and settings polish

Persist visibility and orientation preferences, tune panel sizing, add translations and improve compatibility diagnostics.

## Later evaluation

- Weapon rendering.
- Mouse drag or mouse-wheel rotation.
- Zoom controls.
- Compatibility with custom races, facial animation and alternative pawn renderers.
